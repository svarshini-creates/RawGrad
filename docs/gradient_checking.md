# RawGrad Gradient Checking

## 1. Overview

Gradient checking is a numerical technique used to verify that the
analytical gradients produced by backpropagation are correct.

RawGrad implements backpropagation manually using NumPy. Because the
gradients are not generated by an automatic differentiation framework,
gradient checking provides an important independent validation method.

The basic idea is:

```text
Analytical Gradient
        ↓
Backpropagation
        ↓
Compare
        ↑
Numerical Gradient
        ↑
Finite Differences
